# yiyi-interactive-portfolio
## How to read this repository

This repository is structured as a single source of truth for my professional profile.

- `/content/qa_en.md` contains complete, recruiter-readable answers to core professional questions.
- `/content/keywords.json` maps visible questions to internal keys for structured navigation.
- `/content/evidence.json` provides verifiable external evidence supporting selected answers.

Evidence items are intentionally limited to publicly accessible or reviewable materials.
